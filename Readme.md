> Hybrid **FAISS + BM25** Retrieval-Augmented Generation chatbot built with LangChain and Streamlit. Tested against RAGAS benchmarks with faithfulness, accuracy, and relevance scoring above **0.92**.

### 🧩 AutoStream AI Agent
